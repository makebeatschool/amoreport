# 📊 Скрипт отчётности из amoCRM в Telegram

## 📌 Описание

Этот проект — это автоматизированный скрипт, который собирает данные из amoCRM за выбранную дату, обрабатывает их и отправляет отчёты менеджерам и телемаркетологам в Telegram.

Скрипт работает полностью автономно и обычно запускается по расписанию на сервере.


## ⚙️ Как работает скрипт

При запуске происходит следующая последовательность действий:

1. **Обновление токенов доступа**

   * Скрипт использует OAuth2 авторизацию amoCRM.
   * Access token и refresh token хранятся в файле `tokens.json`.
   * При каждом запуске access token обновляется автоматически через refresh token.

2. **Особенность refresh token**

   * Refresh token является **одноразовым**.
   * После каждого использования он обновляется.
   * Если токен утерян или истёк — требуется ручное восстановление (см. инструкцию ниже).

3. **Определение даты**

   * Если дата передана аргументом — используется она.
   * Если нет — берётся текущая дата.

4. **Запрос данных из amoCRM**

   * Выполняется запрос к API amoCRM за указанную дату.

5. **Обработка данных**

   * Данные фильтруются и форматируются отдельно для:

     * менеджеров
     * телемаркетологов

6. **Отправка отчётов**

   * Готовые отчёты отправляются в Telegram.

7. **Обход блокировок**

   * Для стабильной работы используется обход через Cloudflare.

8. **Автоматический запуск**

   * Скрипт запускается на сервере через `cron`.


## ▶️ Запуск

### Запуск с указанием даты:

python app.py 2026-04-21

### Запуск без аргументов (сегодняшняя дата):

python app.py


## 📁 Структура данных

* `tokens.json` — хранит access и refresh токены
* `app.py` — основной файл запуска
* функции:

  * получение данных из amoCRM
  * обработка статистики
  * отправка сообщений в Telegram


## ⚠️ Важные моменты

* Refresh token **одноразовый**
* При каждом запуске файл `tokens.json` обновляется
* Нельзя использовать старый refresh token повторно
* При сбое авторизации потребуется ручное восстановление


## 🔐 Инструкция по обновлению токена

Если refresh token перестал работать:

1. Перейдите в amoCRM:
   https://makebeatschool.amocrm.ru/amo-market/#category-installed
   

2. Найдите интеграцию:
   Внешняя интеграция (OAuth2)
   
3. Откройте вкладку:
   Ключи и доступы
   
4. Скопируйте **одноразовый код авторизации**
   * действует 1 раз
   * срок жизни — ~20 минут

5. Вставьте код в переменную:
   AUTH_CODE = "сюда_код"
   
6. В файле `app.py`:
   * закомментируйте:
     refresh_token()
     main()
   * раскомментируйте:
     get_tokens()
     

7. Запустите скрипт один раз:
   python app.py
   

8. После успешного обновления токенов:
   * верните всё обратно:
     refresh_token()
     main()
   * закомментируйте `get_tokens()`

9. Скрипт снова готов к обычной работе.


## ⏱ Автоматический запуск (cron)

Пример задания в `crontab`:

30 18 * * * /usr/bin/python3 /app.py

Это будет запускать скрипт каждый день в 21:30.(сервет отстаёт на 3 часа)
